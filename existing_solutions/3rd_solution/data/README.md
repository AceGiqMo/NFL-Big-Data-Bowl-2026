# Data

Place the Kaggle CSV files here locally. Do not commit the datasets to GitHub.

Expected files, for example:

```text
input_2023_w01.csv
output_2023_w01.csv
input_2023_w02.csv
output_2023_w02.csv
```

The `.gitignore` in this folder excludes the data, processed pickles, checkpoints and generated outputs.
